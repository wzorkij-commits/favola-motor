# Favola · мотор (favola-api)

Серверная часть приложения Favola. Родитель пишет, что случилось у ребёнка. Мотор собирает сказку:
текст, шесть иллюстраций, озвучку. Сайт и приложение живут в другом проекте (favola-vercel-1) и сюда не входят.

Этот репозиторий чистый: в корне лежат только `api/`, `lib/`, `data/`, `scripts/`, `package.json`, `vercel.json`.
Ничего лишнего сюда не кладём. Root Directory в настройках Vercel остаётся пустым.

## Функции (их ровно одиннадцать)

На бесплатном тарифе Vercel функций не больше двенадцати. Новые файлы в `api/` не добавляем.
Новый адрес делаем переадресацией в соседний файл: строка в `vercel.json` и метка `__r`, которую читает `lib/route.js`.

| файл | что делает |
|---|---|
| `api/triage.js` | разбирает запрос: безопасность, досье случая, тема, возраст, рецепт и уроки |
| `api/story.js` | черновик двумя половинами (`part: "a"` части 1–3, `part: "b"` части 4–5, вопросы, кадры) |
| `api/polish.js` | точечная редактура и проверка по своду правил |
| `api/image.js` | один кадр |
| `api/voice.js` | одна дорожка. Внутри же `/api/clean`, `/api/transcribe`, `/api/scenes` |
| `api/hero.js` | лист персонажа |
| `api/stories.js` | сохранение сказок, файлы в Blob |
| `api/account.js` | полка и оплаченное. Внутри же `/api/spend`, `/api/forget` |
| `api/auth.js` | вход через Google. Внутри же `/api/otp` (вход по коду на почту) |
| `api/pay.js` | начало оплаты. Внутри же `/api/pay-status` |
| `api/ping.js` | самопроверка, шесть живых проверок |

## Как пишется сказка

1. `triage`: если в запросе насилие, принуждение или самоповреждение, сказки не будет, приложение покажет телефоны доверия. Это решают ключевые слова до модели и досье после неё.
2. Модель заполняет досье случая (что случилось, «хочу» и «надо» героя, неверный вывод, инструмент и его ручка, детали запроса, закладки).
3. Код выбирает рецепт: по одному значению с девяти осей (форма, голос, смешное, закладка и отдача, последний образ, вход помощника, передача ручки, подтекст, место). Значения подходят по возрасту и тону, а рецепты последних сказок устройства (`recent`) выбираются реже.
4. `story` пишет две половины, `polish` правит. Браузер считает заходы, до трёх.
5. Шестая часть никогда не пишется моделью. Она берётся дословно из `data/panel6.json` и сверяется байт в байт.

## Где что лежит

| путь | что |
|---|---|
| `lib/bible.js` | Библия сказок (версия 3) и сборка всех промптов |
| `lib/catalog.js` | каталог вариативности: девять осей, около ста двадцати значений |
| `lib/recipe.js` | выбор рецепта, память о прошлых сказках |
| `lib/variety.js` | имена героя, тип помощника; собирает рецепт |
| `lib/lessons.js`, `data/lessons.json` | библиотека уроков из книг |
| `lib/guardrails.js` | свод правил в трёх уровнях: `hard` (безопасность, блокирует), `craft` (ремесло, до трёх переписываний, потом выходит с пометками), `soft` (на вычитку, не блокирует) |
| `data/*.json` и `data/*.js` | конструкты, шестая часть, герои, инструменты, образец, уроки |
| `lib/store.js`, `lib/blob.js` | хранилище Upstash Redis и файлы в Vercel Blob |
| `lib/plans.js`, `lib/sumup.js`, `lib/h-*.js` | тарифы, оплата SumUp, обработчики переадресаций |
| `lib/owner.js` | безлимит для владельца |

Правило свода: сказка должна собираться всегда. Блокирует только безопасность.

После правки любого `data/*.json` выполнить `npm run data`: он обновляет парный `data/*.js`. Оба файла лежат в репозитории.

## Проверки без ключей

```
npm run check
```

Проверяет: что каждый файл импортируется, свод правил, владельца, запись голосом, весь конвейер сказки на подменённых ответах модели и каталог вариативности (шестьсот рецептов). Ничего не отдавать в работу, пока проверки не зелёные.

## Ключи

Живут только в Vercel, Settings, Environment Variables. Список названий в файле `env.example`. В репозиторий, в чат и в код ключи не попадают. Vercel запоминает набор переменных в момент сборки: завёл хранилище или добавил ключ, сделай Redeploy.

## Хранилища

- Upstash for Redis (аккаунты, полки, оплаты): ключи `KV_REST_API_URL`, `KV_REST_API_TOKEN`. Мотор ходит по HTTP, обычный `REDIS_URL` (Redis Cloud) он не понимает.
- Vercel Blob (картинки и озвучка сохранённых сказок): ключ `BLOB_READ_WRITE_TOKEN`. Проверка: `GET /api/stories?device=любое` должен вернуть поле `файловое_хранилище: true`.

## Заливка

Через веб-интерфейс GitHub, только из Chrome (Safari расплющивает папки). Загрузка не удаляет лишнее: убранные файлы удаляются руками, иначе они останутся и число функций вырастет.
